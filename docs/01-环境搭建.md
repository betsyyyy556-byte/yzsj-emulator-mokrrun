# 01 · 环境搭建：MuMu 6.0 + Android 15 + KernelSU + ADB

## 1. 安装路径与实例

```
MuMu 主程序   D:\MuMu\MuMuPlayer-6.0\nx_main\MuMuManager.exe
设备组件      D:\MuMu\MuMuPlayer-6.0\nx_device\15.0\
实例数据      D:\MuMu\MuMuPlayer-6.0\vms\MuMuPlayer-15.0-0\
ADB           D:\MuMu\MuMuPlayer-6.0\nx_device\15.0\shell\adb.exe
ADB 端口      127.0.0.1:16384
```

MuMu 6.0 的安装包是**组件化 NSIS**，直接双击组件包会报 `80010`。正确做法是带编排参数静默安装：

```powershell
$setup = 'D:\pao\dl\MuMu_6.0.4_gw-win_zh-Hans_1791433010.exe'
$txn = [guid]::NewGuid().ToString()
Start-Process $setup -ArgumentList @(
  '/from_orchestrator=1','/action=install_prepare',"/txn_id=$txn",
  '/silent=1','/product_version=6.0.4','/auto_start=false',
  '/fchannel=gw-win',"/D=D:\MuMu\MuMuPlayer-6.0"
) -Wait
```

先装 `nx_main`（主程序），再装 `nx_device\15.0`（Android 15 设备镜像），两步都要带以上参数。

## 2. 启动顺序（容易踩的坑）

`MuMuManager.exe` 依赖 `MuMuNxMain.exe` 的后台服务，**先起主程序再发指令**，否则会返回：

```json
{ "errcode": -503, "errmsg": "mainnx connect failed" }
```

```powershell
Start-Process 'D:\MuMu\MuMuPlayer-6.0\nx_main\MuMuNxMain.exe'
Start-Sleep 20
& $MGR control -v 0 launch      # 启动实例
& $MGR info -v 0                # 轮询 is_android_started 直到 true
```

## 3. 开启 Root 与 ADB

MuMu 自带 KernelSU（内核 32525-2 / GKI），开启方式：设置 → 其他 → Root 权限 → 勾选。

注意：**KernelSU 环境下 `su` 不在 PATH 里**，`adb shell su -c id` 会报
`/system/bin/sh: su: inaccessible or not found`。

正确用法是 `adb root`：

```powershell
& $ADB -s 127.0.0.1:16384 root
Start-Sleep 4
& $ADB -s 127.0.0.1:16384 connect 127.0.0.1:16384
& $ADB -s 127.0.0.1:16384 shell id
# uid=0(root) ... context=u:r:su:s0
```

## 5. 传感器现状（本方案失败的根源）

```
$ adb shell dumpsys sensorservice | grep -i -E 'step|accelerometer'

0000000000) 3-axis Accelerometer | STMicro | type: android.sensor.accelerometer(1)
```

- **只有加速度计**
- 没有 `STEP_COUNTER(19)`、没有 `STEP_DETECTOR(18)`
- 系统日志里 HAL 自己也报错：

```
SensorsMultiHal: Failed to load subHal config file: /odm/etc/sensors/hals.conf
```

## 6. 常用运维命令

```powershell
& $MGR control -v 0 launch     # 启动
& $MGR control -v 0 restart    # 重启（改了模块/LSPosed 后必须重启）
& $MGR control -v 0 shutdown   # 关机
& $MGR info -v 0               # 状态
```

屏幕分辨率 1080×1920，可用 `adb shell input tap X Y` 操作常规界面；
**但悬浮窗（TYPE_APPLICATION_OVERLAY）收不到 adb 注入的触摸事件**，那个「开始」按钮只能人工点。
