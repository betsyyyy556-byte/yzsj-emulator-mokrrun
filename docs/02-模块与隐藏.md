# 02 · 模块与隐藏：ZygiskNext / Vector / Shamiko / HMA

## 1. 组件清单

| 组件 | 版本 | 作用 |
|---|---|---|
| ZygiskNext | 1.5.3 (880-22a1bf5) | 提供 Zygisk 运行环境（KernelSU 原生不带） |

## 2. 安装 KernelSU 模块

```powershell
& $ADB push zygisk-next.zip /data/local/tmp/
& $ADB shell "/data/adb/ksud module install /data/local/tmp/zygisk-next.zip"
```

**Shamiko 会失败**：

```
Error: Failed to install module script
```

改为手动解包投放：

```powershell
7za x Shamiko-v1.2.5-414-release.zip -oD:\pao\out\shamiko -y
& $ADB push D:\pao\out\shamiko /data/adb/modules/zygisk_shamiko
& $ADB shell "chmod -R 755 /data/adb/modules/zygisk_shamiko"
```

重启实例后生效（`/data/adb/modules/<name>/` 需存在 `module.prop`）。

## 3. Vector 数据库的坑（重点）

配置文件：`/data/adb/lspd/config/modules_config.db`（SQLite）

```sql
-- 表结构
modules(mid, module_pkg_name, apk_path, enabled, auto_include)
scope(mid, app_pkg_name, user_id)
```

**三个必踩的坑：**

1. **重装模块 APK 会把 `enabled` 重置为 0**，作用域行被清空
   → 表现：模块界面一切正常，但注入完全没生效，应用读的是真实定位

2. **daemon 有缓存**，改完数据库必须 `restart` 实例，否则不加载

3. 重装后 `apk_path` 可能指向旧路径，导致加载旧 dex
   → 现象：改了代码但日志还是老的（本项目被这个坑掉了很多时间）

修复模板：

```sql
insert or replace into modules(mid,module_pkg_name,apk_path,enabled,auto_include)
values(20,'com.mokrun.app','/data/app/.../base.apk',1,0);

insert or replace into scope(mid,app_pkg_name,user_id)
values(20,'com.zjwh.android_wh_physicalfitness',0);
```

```powershell
& $ADB push fix.sql /data/local/tmp/
& $ADB shell "sqlite3 /data/adb/lspd/config/modules_config.db < /data/local/tmp/fix.sql"
& $MGR control -v 0 restart
```

> 注意：设备上 `content update` 与 `logcat | grep` 偶发 `Segmentation fault`，
> 改用「文件方式执行 SQL」+「把日志拉到宿主机再过滤」更稳。

## 4. 环境隐藏清单

- Shamiko：隐藏 Root 与模块挂载
- HideMyApplist：把 `com.mokrun.app`、`org.matrix.vector.manager` 从目标应用的可见列表里摘掉
- 模块自带反检测：`Location.isMock` / `isFromMockProvider` 强制 false，并 hook `getInstalledPackages` 过滤包名
- 关闭开发者选项里的「选择模拟位置信息应用」（如不需要系统级 mock）

## 5. 常见现象对照

| 现象 | 原因 |
|---|---|
| 定位纹丝不动、界面显示真实位置 | Vector 里模块 `enabled=0` 或作用域空了 |
| 改了模块但行为没变 | daemon 缓存未重启实例 / 加载了旧 apk_path |
| 悬浮窗按钮点不动（adb 注入无效） | overlay 窗口不接收 `input tap`，需人工点击 |
| 运动世界提示「不在有效区域内」 | 模块未生效，读到的是真实定位 |
